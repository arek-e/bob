# Security policy

## Scope

This public repository contains the Bob Runtime application and self-hosting
contract. Managed production infrastructure stays in the private Control
Plane repository.

## Report a vulnerability

Do not open a public issue for a security problem. Send a private report to the
repository maintainers with a description, impact, reproduction steps, and a
safe contact method.

Do not include credentials, personal data, OAuth values, or production host
details in the report.

## Supported releases

Only the latest release on the default branch receives security fixes during
this early project phase.

Never commit secrets. Use the staged secret scan before a pull request.
